# Hand Ritual tutorial source

Remotion 4.0.537, 1920×1080, 60fps, 24 seconds, silent. Original schematic animation based on verified gesture behavior; no camera footage.

Install: `npm ci`
Preview: `npx remotion studio src/index.ts`
Render: `npx remotion render src/index.ts HandRitualTutorial ../../app/assets/tutorial/hand-ritual.mp4 --codec=h264 --crf=22 --concurrency=2`

Captions are authored in each lesson. App first-use, skip, replay and reduced-motion behavior is handled separately in app/app.js.
