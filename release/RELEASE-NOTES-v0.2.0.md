# The Celestial Archive v0.2.0

Friend-preview release for the public website, Android, Windows, and macOS.

Highlights:

- Two-page reading export with a spacious card-mapping archive.
- Improved mobile gesture tracking, pinch selection, deck focus, and visible guidance.
- Clearer Choose → Draw → Reveal → Meaning visual hierarchy.
- Stronger music and sound-effect defaults with local controls.
- Export and save ceremonies restored across supported browsers.
- Privacy-safe local diagnostics export for troubleshooting; no camera frames or reading text are collected.
